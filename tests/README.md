Ejecutar `node tests/collection.test.mjs` para verificar recogida única, selección de carril, cruce entre fotogramas, bonus de conjunto y estado de una nueva bajada.

Los coleccionables aparecen cada 22 metros, evitando conos cercanos. Los tres primeros están en el centro para enseñar la mecánica; después cambian de carril en grupos. Cada pancho suma 100, cada disco 200 y cada sticker 150. Cada nuevo conjunto de uno de cada tipo suma 250 extra. Los contadores son de la bajada actual y se reinician al volver a empezar.
